# 三分钟演示脚本

## 演示目标

在有限时间内展示项目价值、CodeArts 开发过程、华为云资源使用和最终运行效果。

## 0:00-0:20 问题与方案

画面：浏览器扩展和云上 Demo 首页。

讲解内容：

- 用户阅读英文网页、论文和视频字幕时，需要低打扰的双语翻译。
- 比赛版本在本地翻译能力基础上增加云端翻译记忆和热点缓存。

## 0:20-0:50 CodeArts 开发过程

画面：CodeArts 项目窗口、比赛分支、智能体计划和代码 Diff。

讲解内容：

- 使用 CodeArts 完成需求理解。
- 使用 CodeArts 生成云服务和可视化 Demo 代码。
- 使用 CodeArts 定位问题并补充测试。

## 0:50-1:20 RDS 与 Redis 开通

画面：Skills 调用过程、RDS 控制台和 Redis 控制台。

讲解内容：

- 通过 Skills 创建华为云 RDS 和 DCS Redis。
- RDS 用于保存翻译记忆和调用记录。
- Redis 用于缓存热点翻译。

## 1:20-1:45 云上部署

画面：部署日志、公网 URL 和健康检查。

讲解内容：

- 使用 auto-deploy Skill 将应用部署到华为云。
- 展示部署成功状态和应用公网访问地址。

## 1:45-2:30 核心功能演示

画面：公网 `/`（网站翻译 Demo）与 `/workbench/`（云端可视化工作台）两个页面。

演示顺序：

1. 打开 `/`，点击「翻译网页」：英文正文被逐段翻译并注入页面，下方表格逐段显示缓存层、延迟、服务来源与回退状态。
2. 切换「仅中文」：原文隐藏、只保留译文；切到「双语」：原文与译文对照（长段落走可读配对布局）；切回「原文」：注入内容全部移除、DOM 完全还原。
3. 点击「新增动态段落」：MutationObserver 捕获新内容，再次翻译后新段落同样被翻译。
4. 打开 `/workbench/`，用同一段文本翻译一次：首次走上游调用（缓存层显示 `upstream` 或 `disabled`）。
5. 再次翻译相同内容：缓存层显示 `redis` 命中，延迟下降；调用记录与 RDS 记忆条目同步增长。
6. 展示 `/health`：`api`、`rds`、`redis`、`upstream` 四项均为 `up`。
7. 把 Demo 顶部 API 地址改成一个不可达地址再翻译一次：逐段标记「回退=是、服务=mock」，说明云端异常时不影响阅读。

## 2:30-3:00 开源与结果

画面：GitHub 仓库、README、许可证、测试结果和最终 Tag。

讲解内容：

- 项目源代码、部署指南和使用文档均已开源。
- 项目使用 MIT 许可证。
- 展示最终提交、Tag 和可复现测试结果。

## 录制检查

- 视频分辨率至少 1080p。
- 字体和终端内容清晰可读。
- 不显示密码、AK/SK、Token 和个人信息。
- 配音或字幕至少包含一种。
- 上传后把链接填入 `05-evidence-index.md`。
