# 比赛证据截图目录

本目录只保存经过筛选、允许公开的比赛证据截图。所有截图都应能够证明真实操作或真实运行结果。

## 命名规则

```text
01-codearts-project.png
02-codearts-plan.png
03-codearts-diff.png
04-codearts-validation.png
05-skills-rds-redis.png
06-rds-console.png
07-redis-console.png
08-rds-redis-health.png
09-deployment.png
10-public-demo.png
11-health-check.png
12-cache-flow.png
13-validation.png
```

## 截图要求

- 使用 1080p 或更高分辨率。
- 保留 CodeArts、华为云控制台或应用页面的上下文。
- 同时显示项目名、分支名、资源状态或运行结果。
- 不得出现密码、AK/SK、Token、手机号和账号敏感信息。
- 重要文字不可模糊，截图不得经过影响真实性的编辑。

## 视频和大型文件

演示视频、原始录屏和大型构建包不直接提交到本目录。请上传到 GitHub Release、Gitee 或可靠网盘，并把链接登记到 `docs/competition/05-evidence-index.md`。

## 登记方式

每新增一张截图，都需要在 `docs/competition/05-evidence-index.md` 中补充：

- 证据编号
- 证明内容
- 截图路径
- 操作时间
- 对应 Git 提交
